**ricow 已有的、比主流更硬的资产**（别丢）：

- **AI 对话 + 确认流**：主流没有等价物，"帮助"的终极形态本可以是"直接问"。
- **术语表 41 词条**（`web/terms.rs:19/216`，中英双语、有"报告指标名 ↔ 词条"双向核对测试）。

- **零依赖零构建前端 + 单二进制**（禁一切 CDN / 框架 / 打包链）。

**差距的共性**：主流都&#x662F;**"把已有信息推到用户眼前"**（引导、tooltip、CTA、可操作错误）。  
ricow 的问题恰恰是**信息已有、但停在数据层没冒到 UI**（0.3 第 1 条就是标本）。

## 三、优化计划（四批 · 按"用户价值 ÷ 改动成本"排序）

> 纪律约束（**全程不破**）：零依赖零构建 · 禁 CDN/框架 · 面板只读（D17）· 用户数据只走  
> `textContent`/`createTextNode` · 双语（`data-zh/data-en` + `R.TEXT`）· 诚实性三态 ·  
> 新增资产进 `assets.rs::ASSETS` 单一清单 · 每项走 SDD + `e2e_web.py` 断言增量。

### 批次 A ——「看得懂」：把已有信息推到眼前（**建议先做，成本最低**）

**A1 · 策略适用性卡片（P0，后端零改动）**

- 问题：8 个内置策略选型只能靠名字猜；`suitable/unsuitable/description` 已写好但不显示。
- 方案：只读详情页（或列表展开区）渲染 `summary / description / suitable / unsuitable`；  
  列表行加"适用"摘要。数据源：`GET /api/strategies/{id}` 已返回完整 `manifest`（`web/strategies.rs:54-86`），  
  **后端一行不用改**。内置策略的详情入口从"仅复制"改为"详情 + 复制"。
- 验收：选 `shannon_hedge_grid_futures` 能看到"适用/不适用"两行且与 TOML 逐字一致；  
  `e2e_web.py` 增断言：`/api/strategies/{id}` 响应含 `suitable` 字段 + 详情页 DOM 出现该文本。

**A2 · 术语表升级为"全局可查"（P0）**

- 问题：41 条术语只服务对话流，市场/策略/运行页的同一批指标名**点不了**。
- 方案：把术语索引从 `chat.js` 上提到 `common.js`（`R.terms` 单例，一次取用全局共享）；  
  顶栏加 `?` 按钮打开**术语表全表检索**（按中文/英文/key 过滤）；`decorateTerms` 复用到  
  回测报告、运行页、市场页的指标名。**仍然只产 DOM，零 `innerHTML`**。
- 验收：市场页"回撤"、运行页"已实现盈亏"可点出解释；术语面板可搜索；`node --check` 全过。

**A3 · Web 内置帮助中心（P1）**

- 问题：没有"从这里开始"。`/help` 的丰富内容（工具白名单、13 类写动作、常见事怎么办，`session.rs:1090`）  
  只在对话里，用户不问就看不到。
- 方案：顶栏"帮助"抽屉，分三块：**① 5 分钟上手**（装→配密钥→选策略→回测→Dry Run→实盘确认流）  
  **② 术语速查**（复用 A2）**③ 常见问题**（"为什么 0 成交"、"为什么启动被拒"、"面板为什么不能下单"）。  
  数据可内置为静态资产（`help.js` + `HELP.md` 文本），**不引外部文档站**。
- 验收：帮助内容与 `help_text()` 口径一致（有一条测试盯住"两处都提到 13 类写动作"）；  
  双语齐全。

### 批次 B ——「找得到 / 顺手」：可发现性与导航

**B4 · 空状态 → 可操作 CTA（P1）**

- 现状：空状态只有一行灰字（`chat.js:725 emptyRow`、`markets.js:278 mk-empty`）。
- 方案：每个空状态给**下一步动作按钮**：零策略→"从模板新建"/"看看内置策略"；  
  未配密钥→"去密钥页"；零会话→"新建会话并问我"；零运行→"先回测一个策略"。
- 验收：四个视图空态均有 CTA 且点击落到正确视图；禁内联事件（沿用 `assets.rs` 白名单断言）。

**B5 · 首次运行引导（Web onboard，P1）**

- 现状：CLI 有 `onboard`，Web 无。新用户进网页面对 6 个空视图。
- 方案：检测"从未配置过密钥且无会话"→ 顶栏下方显示一条**可关闭的任务清单**  
  （配密钥 → 选策略 → 跑回测 → 开 Dry Run → 看运行），完成一项打勾。状态**不落浏览器存储**  
  （纪律禁 `localStorage`），改由服务端 `/api/config` 派生（"是否已配密钥"等事实已在后端）。
- 验收：全新 `RICOW_ROOT` 下走一次能跑完全流程；重开不再显示（依据服务端事实而非本地存储）。

**B6 · 全局 toast（P2）**

- 方案：`R.toast(msg, kind)` 单一出口，替代各视图散落的 `showMsg`；跨视图操作（保存后跳转）不再丢提示。
- 验收：保存策略后跳到列表仍能看到"已保存"；aria-live 保留可访问性。

**B7 · 命令面板 / 快捷键（P2，可选）**

- 方案：`Ctrl/⌘+K` 打开：跳视图 / 切语言 / 切主题 / 搜索术语 / 搜策略。纯前端，复用 A2/A3 数据。
- 验收：键盘可完成"跳策略页 + 搜术语"；不拦截输入框内的按键。

### 批次 C ——「对得上」：能力对齐与一致性

**C8 · Web 参数寻优升级为多维（P1）**

- 问题：CLI `ricow optimize` 支持多参数网格/随机搜索，Web 只有单参数 sweep → **能力不对称**。
- 方案：把 `optimize` 的网格展开/打分/排序抽为可复用内核（`commands/optimize.rs` 已有，**抽到 lib 或复用其纯函数**），  
  Web 新端点 `POST /api/backtest/optimize`（多 `--param` 维度 + 组合数 >100 拒绝 + 逐组进度），  
  前端出**组合对比表 + 按指标排序 + 最优行高亮**。**仍不改引擎**（复用 `backtest.rs` 的 `run_backtest`）。
- 验收：同网格下 Web 与 `ricow optimize` 报告逐位一致；组合数护栏生效；`e2e_web.py` 增断言。

**C9 · 回测结果对比（P1）**

- 问题：050 提速后用户会跑大窗口，结果更难人工比。
- 方案：结果区支持"与本策略上一次结果对比"（服务端已有回测归档可派生）：关键指标并排 + 差值着色  
  （**涨红跌绿**，沿用 `--error`/`--accent`）；可选"叠加基线"在权益曲线上画第二条线。
- 验收：同一策略跑两次，第二次显示差值；曲线叠加不破 `series.update()` 时间单调检查。

**C10 · 盘口深度条（P2）**

- 方案：每行按累计量 `linear-gradient` 背景着色（无需新图表库），买红卖绿沿用主题变量。
- 验收：深度条随 SSE 盘口帧更新；`prefers-reduced-motion` 下不抖动。

**C11 · 数值/时间格式化统一（P2）**

- 问题：`formatNum`（截尾零）、盘口原始字符串、会话时间与交易时间戳两套口径并存。
- 方案：`common.js` 收一个 `R.fmt.num/price/pct/time`，按 `lang` 走 `Intl.*`；全站替换。
- 验收：切换语言后时间/数字本地化一致；有单测（见 D13）。

**C12 · 响应式补断点（P1，原分析 P1-8）**

- 现状：5 处断点，交易/策略/运行三视图窄屏可用性无保障。
- 方案：给**对话 + 运行**两个高频视图补 `≤900px` 断点（侧栏可折叠、面板改抽屉）；  
  策略页表格窄屏改卡片式。桌面优先不变。
- 验收：1366×768 与 1024×768 下核心动作可达；`e2e_web.py` 无回归。

| 批次    | 内容                                    | 价值           | 成本 | 建议     |

**如果只做三件事**：**A1（策略适用性）+ A2（术语全局化）+ B4（空状态 CTA）** ——  
三项都只动前端、零引擎改动，却直接解决"看不懂 / 找不到"这两个最痛的问题。

**分两批做**（一次做太多会稀释验收纪律）。这里说的"批"就是**本文档的批次 A/B/C/D**，没有另立一套编号：

- **第一批：帮助与可发现性** = A1 + A2 + A3 + B4 + B5 + B6 —— 全是前端，主题是"用户看不看得懂、找不找得到"。**已全部落地**（见 §二·五）。
- **第二批：与 CLI 能力对齐 + 专业度** = C8 + C9 + C12（含少量后端） + B7/C10/C11 —— 主题是"Web 有的能力别比 CLI 少"。

## 六、明确不做（守住 ricow 的立场）

- **不引 Vue/React + 打包链**：违反单二进制/零供应链决策；6→7 个视图手写 IIFE 仍可控。
- **不引 TradingView 官方库 / 任何 CDN**：许可重、体积大、需联网，与"完全本地化"冲突。
- **不做网页端直接下单/撤单**：D17 只读面板 + 对话确认流是**资金安全卖点**，不是落后项。
- **不做完整 CommonMark / 语法高亮到对话流**：044 的受限子集已够用。
- **不做云端帮助站**：帮助内容内置进二进制，`include_str!` 分发。
- **不做贝叶斯/TPE 智能寻优**：C8 只对齐 CLI 已有的网格/随机，不扩语义。
