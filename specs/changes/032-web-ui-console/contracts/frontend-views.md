# 前端视图契约: 032 Web UI 工作台化

## 导航与路由

- hash 路由:`#chat`(默认)、`#markets`、`#strategies`、`#runs`、`#settings`;二级详情用 `#markets/{symbol}`、`#strategies/{id}` 形式,由 router.js 解析
- 刷新/直达链接恢复视图;切视图不打断 SSE(chat.js 的 EventSource 在离开对话视图时保留连接,返回时不重建,除非已 Closed)
- 左侧导航五项 + 当前高亮;语言切换控件仍在顶部,全视图生效(沿用 data-zh/data-en + TEXT 字典机制)
- 全局:`window.Ricow` 命名空间;`common.api(path, opts)` 统一带 token;任何视图禁止 localStorage/sessionStorage 写密钥

## 视图 1: 对话 #chat
- 完整保留现有三区(会话列表 / 对话流+输入 / 策略·交易·日志面板),DOM 可重排进 `#view-chat` 但行为零回归
- 斜杠命令、流式着色、口语词确认、面板轮询逻辑原样迁入 chat.js

## 视图 2: 市场 #markets
- 顶部:视野开关("只看 bStock"/"显示全部",绑定 `market.show_all_pairs`,切换即调 POST config 并刷新)、搜索框、视野标注("过滤视野 · 现货 N · 合约 M")
- 两列:现货表 / 合约表(符号可点);数据 `/api/markets`
- 详情 `#markets/{symbol}`:面包屑返回;现价(mid)+ 买卖盘(左)+ K 线(右/下);周期选择 15m/1h/4h/1d;lightweight-charts candlestick + volume 可选
- 错误态:失败卡片 + 重试按钮;加载骨架;不展示伪数据

## 视图 3: 策略 #strategies
- 左栏:分组列表(现货/合约 × 内置/用户),每项名称+市场+来源徽标;顶部"新建空白"按钮;每项操作:内置[查看][复制];用户[编辑]
- 详情/编辑器 `#strategies/{id}`:
  - 基本信息(名/市场/说明,新建可编辑,已存用户策略名不可改)
  - 参数表单按 manifest params 渲染(f64/i64/string/bool/enum),默认值预填
  - 标的选择(可从市场页带参跳入)、市场选择(仅新建)
  - Lua 编辑区(textarea,等宽字体,Tab 插入两个空格)
  - 操作按钮:[AI 修改] [回测] [保存];运行中策略保存禁用并提示
- AI 修改:展开指令输入条 → loading → 返回代码替换编辑区内容(顶部显示"AI 草稿,未保存"标记,可撤销还原)→ 用户手动保存
- 回测:参数/标的/周期/天数表单 → 发起后轮询(1s)→ 报告区展示(先 `<pre>` 全文;指标结构化渲染沿用后续增强);可离开,返回时若作业完成则展示
- 复制向导:选内置 → 弹名输入(实时前缀/保留名校验反馈)→ 落盘后进编辑器

## 视图 4: 运行 #runs
- 实例表:名称/模式/状态/运行时长/标的/净收益/成交数;每 5s 刷新(页面不可见时暂停轮询)
- [启动]对话框:选策略(内置/用户)→ 市场/标的/参数(从 manifest 生成表单)→ 模式单选:
  - Dry Run:确认按钮("启动 Dry Run")
  - demo:确认按钮;缺凭据时按钮置灰+去设置链接
  - live:两步模态——第一步展示风险披露全文(滚动到底才可输入)+逐字输入 `确认风险`(仅首次,已 ack 跳过);第二步逐字输入 `确认实盘 <名>`,短语框旁边给出期望串
- [停止]:确认小框(可选"同时平仓位",仅 live 有意义)→ 停止报告
- [日志]:展开行内日志面板,复用 log SSE
- 三态文案:运行中 / 已停止 / daemon 未运行状态不可知 / 读取失败(沿用现有 TEXT key 风格,中英双语)

## 视图 5: 设置 #settings
- 三组卡片:币安主网(key/secret)、测试网 demo(key/secret,标注可选)、AI(provider 下拉/模型/base_url/key)
- 密钥输入 type=password,占位文案:已配置显示 `已配置 · 尾号 xxxx`(来自 hint),留空保存=不改动
- [保存] 后行内显示成功/失败;提供"当前视野"快捷开关(市场页同款)
- 不做:连接测试按钮(YAGNI,真实操作时自然验证);密钥导入导出

## 可访问性与样式
- 沿用深色系(025 FR-023 与 website/style.css 一致);不引入 UI 框架
- 所有按钮/表单有中文 data-zh 与英文 data-en;无中英叠排
- 移动端不适配(本地桌面工具)
