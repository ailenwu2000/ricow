# 035 功能规格: 实盘行情静默期兜底心跳 tick

**状态**: 已实施 (2026-09-26, 门禁 579 passed / 0 failed / 22 ignored) | **来源**: 034 plan §五 竞品优势清单 #10 (重新验证后确认, 唯一"价值高改动小"项)

## 一、为什么

重新验证 034 plan §五清单 (2026-09-26, 逐项对照当前代码):

- **#10 确认成立**: 实盘主循环 ([command.rs:1105-1154](../../../crates/ricow_engine/src/command.rs)) 中
  `on_tick` 仅由 `LiveEvent::Quote` 驱动。行情流未断但静默时 (低流动性时段/交易所节流),
  策略零决策 —— 网格挂单空窗、成交后重挂被无限期推迟。流**断开**有保护 (Quote(None) → StreamEnded 停机),
  但流**活着却静默**没有任何兜底。
- 其余项均不满足"改动小": #3 对账需 testnet 实盘实测、#1 滑点会动撮合引擎破坏等价性基线、
  #7 低价值、#2/4/5/6/9 维持 YAGNI。故本次只做 #10。

竞品参照: Hummingbot (轮询+事件混合) —— 行情事件 + 周期性心跳兜底。

## 二、范围

**做**: 实盘主循环增加周期性心跳事件 (固定间隔, 不引配置), 心跳触发时用**最后一次** orderbook
调 `strategy.on_tick` 并走与 Quote 分支相同的下单路径。行情正常时心跳是空转冗余 (策略自身有节流/幂等), 语义无损。

**不做**: 不改回测/dry-run 语义 (回测保持逐 bar, 034 D3 口径); 不改策略; 不引可配置参数 (YAGNI,
与 034 D2 "固定常量" 同口径); 不做启动对账 (#3, 后续单独计划)。

## 三、功能需求

- **FR-001**: 实盘主循环存在固定间隔 (常量, 默认 30s) 的心跳; 心跳 tick 调用 `strategy.on_tick`,
  使用最后一次 quote 构建的 orderbook (不虚构价格, 不推进 K 线)。
- **FR-002**: 心跳产出的订单走与 Quote 分支**同一条**下单路径 (计数/落库/拒单回传 on_order_update),
  不得出现第二份重复实现。
- **FR-003**: 心跳不产生新行情事实: 不调 `tick_kline`、不计 `outcome.ticks`、orderbook 为空 (启动后从未收到 quote) 时跳过决策。
- **FR-004**: 心跳失败 (下单 Err) 只计数/记日志, 不中断循环 (与 Quote 分支一致)。
