## 真机验证(2026-10-03, tmp/check-034, 端口 18801, 现场已清理)

- 端点: 默认 `{"theme":"dark"}` → POST light/red 均 200 且 `ricow.toml` 落 `theme = "..."` →
  `blue` 400 (`不支持的主题: blue (可选: dark / light / red)`) 且不覆盖 → 回读一致 → 刷新页面保持。
- 前端: 顶栏下拉三选项; 红/白/深三套主题全页截图人工复核(含右栏面板、卡片、按钮、边框对比度);
  K 线图配色随主题重绘。
- 折叠: 连发两条长消息 → 第一条自动收成两行 + "··· 点击展开" → 点击展开全文 → 再点收起;
  第二条(非最新块)同样收起; 短消息(≤2 行)不出现可点标记。

## 已知限制(如实)

- 首帧永远深色, 主题在 boot 读完 `/api/theme` 才应用(与语言同节拍, 不引入 localStorage 双源)。
- 对话流**回放**(重开会话)时消息来自落库记录, 折叠同样生效; 但无 AI key 的会话轮次
  用户消息不一定落库(既有行为, 与本变更无关)。
- 本环境管道限制(231)导致 `ai_live_smoke` 2 例必红 —— 环境问题, 非 ricow 缺陷。
