# 041 前端开发回路（`--web-assets-dir`）

> 依据: `tmp/webui_analysis.md` 第四节 P1-4 与第六节「第三刀」（对标开发效率缺口，无外部对标软件）。
>
> 现状: 前端 **9 份 JS + 1 份 CSS + 1 份 HTML** 全部经 `include_str!` **编译期内嵌**进二进制
> （`web/assets.rs`）。好处是单二进制、无外部依赖；代价是**改一行 JS 也要 `cargo build` 全量重编**——
> 前端迭代的反馈回路是 1~3 分钟，而实际改的常常是一句文案或一个 class。
>
> 本变更只做**开发回路**这一件事：加一个显式开关，让服务端改从磁盘热读同一批资产。
> `strategies.js`（2626 行）的拆分**不在本变更**，另起变更（拆分要靠这条回路才能快速迭代与验证）。

## 一、需求

- FR-1: `ricow web` 新增 `--web-assets-dir <DIR>`。给出时，前端资产（`index.html`、`style.css`、
  各 `*.js`）**从该目录热读**；不给时行为与现在**完全一致**（仍是编译期内嵌副本）。
- FR-2: **文件名白名单，路径从不来自请求**。可服务的文件名只有编译期常量表里的那一份清单；
  磁盘寻址一律是 `目录.join(常量名)`，请求里的路径**从不参与拼路径**。因此不存在 `..` 穿越、
  不存在任意文件读取 —— 这是用**结构**消灭漏洞，而不是过滤攻击串。
- FR-3: 启动时**校验并规范化**目录：必须存在、是目录、且含 `index.html`。任一不满足 →
  **启动即失败**并给出可操作的中文错误（不在浏览器里白屏、不静默退回内嵌）。
- FR-4: 目录里**缺某个文件**时，该资源请求返回 **500 + 明确文案**（含文件名与目录路径）。
  **不静默退回内嵌副本** —— 退回会让"我明明改了怎么没生效"变成谜（同 040 的诚实性口径）。
- FR-5: 启动时打印**双语警告**（跟随 `[ui].lang`），说明这是开发调试模式、生产应去掉该参数。
- FR-6: 磁盘来源的响应带 `Cache-Control: no-store`，否则浏览器缓存会把"改完刷新"吃掉。
- FR-7: 开关**不放松任何既有约束**：资产仍走**同一批路由**、仍在 **token 中间件之后**，
  不新开端口、不新增放行口；CSP 等安全响应头照旧。
- FR-8: **纪律扫描口径不放松**：唯一清单仍是资产表；首页 ↔ 清单双向对齐断言不变；
  "禁 localStorage / 数据只走 textContent / 面板只读"三条扫描的覆盖面不变。
  磁盘热读只是**调试视图** —— 真正发布的内容仍是内嵌副本，下一次 `cargo build` 把磁盘文件嵌进去时，
  测试照常扫到它。
- FR-9: 资产表**收敛为一份**，路由表由它**循环生成**。历史教训：清单散落在三处导致新增脚本时
  三项断言集体漏扫且全绿（2026-10-05 审查，见 `assets.rs` 注释）。本变更顺手把"路由"也并入派生关系。

## 二、非目标（显式不做）

- **不做热重载 / HMR / 文件监听**：手动刷新（F5）就够，自动推送要引入 SSE 通道与文件监听，
  与收益不成比例（YAGNI）。
- **不做 `strategies.js` 拆分**：2626 行拆 3~4 份是纯重构，diff 大、前端无单测，另起变更。
- **不动发布形态**：`include_str!` 单二进制不变；不引入"从磁盘加载"作为生产默认。
- **不做 `--web-assets-dir` 的 release 门控**：显式给出该参数**本身就是人工确认**
  （同 `[ai].allow_custom_base_url` 的口径）；代价是启动警告必须显眼（FR-5）。
- **不加新依赖**：文件读取走已在的 `tokio::fs`。

## 三、验收

**离线（单测，走真实监听套接字）**

- 不带 `--web-assets-dir`：`/common.js` 的响应体是**内嵌副本**（与磁盘标记内容不同）——
  证明默认行为零变化。
- 带 `--web-assets-dir` 指向含标记文件的临时目录：`/common.js` 的响应体是**磁盘内容**，
  且带 `Cache-Control: no-store`。
- 目录里缺一份文件 → 该资源 500，文案含**文件名**。
- 白名单外的路径（`/nope.js`）→ 404，且响应体不含任何文件内容。
- 无 / 错 token 取资产 → 仍 401、响应体为空（既有断言不变）。
- 无 `index.html` / 不存在 / 不是目录 → `resolve_assets_dir` 返回可操作的错误。

**真机（不可用替身）**

- 带开关起服务 → 在磁盘上改一行 JS → **刷新即见新内容**（无需 `cargo build`）。
- 不带开关起服务 → 改磁盘文件后刷新**看不到**改动（证明内嵌形态没被破坏）。
- 官方冒烟脚本 `e2e_web.py` 零回归（两种形态各跑一次）。
