## 2. 用户点名的优势：bStock 覆盖（本轮重点）

### 2.1 事实（本轮实机实测，服务在 8850 端口）

| 口径 | 现货 | 合约 |
| -- | -- | -- |
| **默认视野**（`show_all_pairs=false`，仅 bStock） | **96** | **187** |
| 全量（`all=1`） | 1383 | 790 |

视野内现货形如 `AAOIBUSDT` / `AAPLBUSDT` / `ADBEBUSDT` / `AGPUBUSDT`…… **美股代币现货 + 股票永续全量覆盖**。

### 2.2 为什么这是优势

币安官方的**机器人/智能组合功能只开放少数几个 stock**；ricow 的视野判据（`market_class.rs::bstock_spot_pool` + `is_bstock_base`）走的是 **fapi EQUITY base 白名单的全量枚举** —— 交易所上了哪个美股代币，ricow 就能跑哪个。

**这个优势现在完全看不见**：用户打开概览只看到四个计数（策略/实例/密钥/会话），没有任何一处告诉他"你能跑 96 个现货 + 187 个合约"。

### 2.3 要做什么

1. **概览页新增「bStock 覆盖」卡**：显示视野内现货/合约数 + 是否处于过滤视野；说明一句"币安官方机器人只开放少数 stock，ricow 覆盖全部美股代币"。
2. **一键放宽视野**：卡上给「查看全部 1383 个现货对」入口 → 跳到市场视图并带上 `all=1`（**不偷偷改用户的 `ricow.toml`** —— 那是配置，改它要用户显式确认；市场视图本身已有"全部/股票类"切换，这里只负责带过去）。
3. **数据来源**：`GET /api/overview` 补 `scope` 字段（`{spot, futures, filtered}`），复用 `pairs::current_view`，**不新造一套取数**。

## 3. 063 遗留项（用户说"参考待完成事宜一起完成"）

### 3.1 「模拟回测」Tab 里的 AI 解读按钮（063 §6 第一项）

- `ai-assess` 端点已存在（`POST /api/strategies/{id}/ai-assess`），前端 `strategy_editor.js` 里已有 `syncAssessPanel()` 与三步串接（跑改前 → 跑改后 → 问影响），但**按钮没接进 Tab**。
- 本轮：在「模拟回测」Tab 的回测结果区加「AI 解读」按钮，复用既有三步逻辑。
- **判据**：有参数改动才显示（`paramDiffs()` 非空）；没配密钥时按钮可见但点了如实报错（`need_keys` → 引导去密钥页）。

### 3.2 fmz 的参数优化 / 重置参数入口（063 §6 第五项）

- fmz 的新建实盘页底部有这两个入口。
- **「重置参数」**：把参数表单恢复成清单默认值 —— 这个**能做且诚实**（有明确的"原值"可比），本轮做。
- **「参数优化」**：fmz 的是穷举/遗传寻优。ricow 已有 `/api/backtest/sweep`（单参数扫描）—— 本轮做**入口**（跳到回测 Tab 的寻优区），**不新造寻优引擎**（那是一个独立变更）。

### 3.3 实盘列表的市场筛选（补 fmz 的"全部种类"）

- fmz 的实盘列表有「全部种类」下拉。ricow 的实盘列表**没有市场列/筛选**。
- 本轮：实盘表加「市场」列（现货/合约徽章）+ 表头筛选（全部/现货/合约）。

## 4. 刻意不做

| 项 | 理由 |
| -- | -- |
| fmz 的**账户余额 / 可用时长**卡 | ricow 无账号，跑多久取决于本机。填一个假余额或假时长 = 编造事实 |
| 自动把 `show_all_pairs` 改成 `true` | 那是**用户配置**。改它必须用户显式确认；市场视图已有切换入口，概览只负责带路 |
| 新造参数寻优引擎 | 已有 `sweep`（单参数扫描）。多参数寻优是独立变更，本轮只做入口 |
| fmz 的账号体系整块 | 062 §3 既定：不留占位 |
