## 2. 撞出来的三个真问题（都已修 + 回归断言）

### 真问题一：我把一个"要联网、可能很慢"的取数放进了 overview 聚合端点

- **现象**：币安不通时 `GET /api/overview` **HTTP 000（30 秒超时）**，四项计数一起拿不到。
- **根因**：`scope` 走 `pairs::current_view` → 拉 exchangeInfo，币安客户端自身超时 30 秒；而 overview 的设计原则是"小到可以每次进页面都拉"。
- **修法**：`tokio::time::timeout(5s)` 包一层，超时 → `scope = None`（前端显示「—」+ 原因），**主计数照常可用**。
- **实测**：5.03 秒返回 `{"strategies":0,...,"scope":null,...}`。
- 回归断言：`test_overview_always_carries_activity_and_alert_arrays`（钉"`recent_sessions`/`alerts`/`scope` 三个新字段**恒在**"—— 前端按 `|| []` 取, 字段缺失时静默走空态, "后端忘了给字段"这件事前端看不出来; 与 062 那条"每项都能是 0"同一用意: 把只在前端做的区分在后端也拦一道)。

### 真问题二：`data-zh` 挂在有交互子元素的标签上，被 applyLang 清空

- **现象**：实盘表头看得见「市场」二字，但**筛选框从头到尾不存在**，且不报错。
- **根因**：`<select id="rn-market-filter">` 挂在带 `data-zh` 的 `<th>` 上；`applyLang` 换语言用 `node.textContent = ...`，而 textContent 赋值**清空全部子节点**。首屏就是"已应用过一次语言"的状态，于是 select 从未存在。
- **修法**：`data-zh` 改挂内层 `<span class="rn-th-market-label">`，select 作为兄弟节点。
- 这与侧栏导航项 `data-zh` 要挂 `.nav-text`（不能挂 `<a>`）是**同一个坑**，已在项目记忆里；本轮补了一条**通用扫描断言**（`test_no_data_zh_on_elements_with_interactive_children`：`bi("...")` 所在行不许再出现 `<select`/`<button`/`<input`/`<textarea`）。

### 真问题三：重置参数点了"没反应"（设计判定 + 体验缺口）

- **现象**：走查里改 `start_price` → 点「重置参数」→ 值不变。
- **根因**：`start_price` 是**必填且无默认值**，而设计是"只回有默认值的键"（清空必填项会让用户面对空表单 + 一句"必填"，那不如不重置）。所以**行为符合设计**。
- **但体验有缺口**：用户不知道发生了什么，会以为按钮坏了。
- **修法**：重置后给一句反馈 ——「已把 N 个参数恢复成清单默认值」或「没有可恢复的参数 —— 这个策略的参数都没写默认值（必填项就是这样），改动需要你自己调整」。

### 币安不通时怎么验 bStock 卡

真机 `scope` 恒为 `null`，验不到"数字与 API 一致"那条。两条路都走了：
1. **真机验"不可读"路径**：`scope: null` → 卡上显示「视野规模暂不可读（交易所快照没拉到），不影响其它数字」，**不给入口**（没有可展示的数字，带路没意义）—— 这正是"取不到 ≠ 0"的正确行为。
2. **mock 验"有数字"路径**（`probe064b.mjs`）：mock `/api/overview` 返回 `{spot:96, futures:187, filtered:true}` → 前端显示 96/187 + 「股票类视野」徽章 + 优势说明 + 入口；再 mock `filtered:false` → 变 1383 + 「全部交易对」。**证明数字真的来自 scope、口径徽章会跟着变**（不是写死的）。
