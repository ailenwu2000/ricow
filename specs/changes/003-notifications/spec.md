# 003 功能规格: 出站通知 (成交 + 熔断/风险告警)

**状态**: 未开始 | **日期**: 2026-09-13 | **依赖**: 004(风控熔断) / 011(实盘) / 014(资金费与强平)

## 一、输入

- `specs/product.md` §三.4 用户旅程承诺: **"随时管理: 多策略启停/查看盈亏; 熔断/成交通知"** —— 通知是产品承诺项, 此前一直缺失(`specs/roadmap.md` 003 挂在 backlog)。
- 现状: 高风险事件**只落本地日志**(`logs/<name>.log`), 用户不在终端前就等于没有:
  - 004 的两级熔断触发(`RiskError` 的熔断类拒单)
  - 014 的接近强平告警(距强平距离低于阈值)
  - 011 的停机残留(撤单兜底后仍有本策略挂单/持仓)
  - 成交通知(product 明确要求)
- 数据不出本机是产品支点(`product.md` §四), 因此通知必须是**用户自选通道**, 平台不内置云端账号。

## 二、用户故事

- **US1**: 作为实盘用户, 我要在**熔断触发/接近强平/停机有残留**时收到一条消息, 而不是事后翻日志。
- **US2**: 作为实盘用户, 我要能给"成交"单独开关与限速 —— 网格策略每分钟多笔成交, 不加节制的通知等于骚扰。
- **US3**: 作为架构师, 我要通知失败**绝不影响交易循环**(网络抖动不能让策略停摆), 且不引入任何云侧依赖。

## 三、功能需求

- **FR-001 通道 = 通用 Webhook(用户自选)**: 策略 TOML `[notify]` 段配置 `webhook`(任意接收 `POST` JSON 的端点)+ 可选 `chat_id`; 一个实现在 Telegram Bot API 形态与通用 webhook(飞书/Slack/自建)之间通用 —— 不引入平台账号、不写死第三方 SDK。
- **FR-002 四类事件**: `fill`(成交) / `circuit_breaker`(熔断拒单) / `liq_warn`(接近强平) / `residual`(停机有残留); `events` 白名单可关闭不需要的类别(省略 = 全开)。
- **FR-003 事件筛选与限速(纯逻辑)**: `events` 白名单 + 同类事件 `min_interval_secs` 最小间隔(默认 5s, 0 = 不限速); 被限速丢弃的事件**计数**并在下次发送时附带(不静默丢)。
- **FR-004 强平告警去重**: 同一 `(pair, 方向)` 在距离恢复前**只发一次**(每 tick 重复告警是刷屏, 不是通知)。
- **FR-005 失败隔离**: 发送失败(网络/非 2xx/超时)只 `warn` 日志, **绝不中断策略循环、不改动任何交易行为**; 请求带短超时(5s)。
- **FR-006 配置与关闭**: `[notify] enabled = false` 或缺省 → 完全不打通道(默认关闭, 与"实盘默认 Dry Run"同一保守口径); 通知器在启动时构造一次。
- **FR-007 内容可读**: 每条消息含策略名、事件类型、关键数据(成交: 方向/数量/价格/手续费; 熔断: 触发规则与阈值; 强平: 距离/强平价/标记价; 残留: 挂单/持仓明细)。

## 四、验收标准

- **SC-001**: `cargo test --workspace` 全绿(基线 289), 现货/回测/实盘路径零回归。
- **SC-002**: 纯逻辑单测 —— 消息格式化(四类)、事件白名单、限速(窗口内压制 + 过期放行 + 丢弃计数)、强平去重。
- **SC-003**: **真实 HTTP 投递验证**: 用本地回环端点接收, 断言收到 `POST` 且 JSON 内容与事件一致。
- **SC-004**: 失败隔离实测 —— 端点不可达时策略循环不受影响(只 warn)。
- **SC-005**: 文档同步: `product.md` §三.4 的承诺标注落地、`architecture.md`(§十一)、`roadmap.md`(003 状态)、`lua-api.md`(若涉及策略侧可见性)、本档案 converge。

## 五、假设

- **A1**: 通道用 webhook 而非内置第三方 SDK —— 个人开源 + 本地优先 + 零账号依赖(Telegram/飞书/Slack 都能被一个 POST 覆盖)。
- **A2**: 通知不是交易决策的一部分(单向、无重试队列、不保证送达); 缺失不影响策略正确性。
- **A3**: 只做**实盘与 Dry Run 运行期**事件; 回测不发通知(无实时性, 无意义)。
