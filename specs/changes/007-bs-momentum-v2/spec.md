## 背景与范围

- **根因**(研究文档 §一, 逐笔配对实测): ①无市场状态门 → 弱市仍追相对强势股,
  买在短期高点(买入后 5 日均 -5.9%), 教科书动量崩溃(Daniel & Moskowitz 2016);
  ②日频检查 + 39% 交易日调仓 + 换手 707%/90 天; ③牛市确认过滤在弱市把 70 池滤到剩 1-2 只
  "最不烂"硬扛(分散失效); ④池含 18 ETF(3x/反向杠杆), 过滤器对池构成天然苛刻。
  费用仅占 1.2% — 非主因。
- **调研结论**(研究文档 §二): 市场级趋势门 = Antonacci 绝对动量门 / 800 年趋势跟随实证中
  最普适的崩溃防护; 调仓频率月/周为主流(周频限低成本大票); top-N 分散(≥3-5)样本外显著
  优于 1-2 只集中。
- **验证约束**(研究文档 §三): bStock 现货仅 91 根、fapi ~220 天 → 90/220 天窗口**无法证明
  长期期望为正**; 唯一长历史源 = 美股 Nasdaq 日线(信号轨现有 ~2514 根/标的)。
  R1 十年回测(006 撤销项)恢复 = 信号轨与成交轨同用美股 Nasdaq 日线(忽略 bStock 溢价与
  24/7 时差, 注明近似); bStock 90/220 天仅作 sanity。

**范围(本次修正)**:
1. 策略语义(v2, 全部 Lua 内可改可参考): 市场门 / 周频 / 持仓下限;
2. CLI 装配与回测: R1 美股十年日线回测路径(成交轨 = Nasdaq);
3. 报告与归因工具正式化(质量指标打印 + 成交/快照/净值导出);
4. 数据源铁律固化(代码注释 + 技能 reference + 本档案), 防止指标误落成交轨。

**范围外**: 实盘组合执行(M3 另行立项); 池构成调整(剔除/分级 ETF — 本次不做, 宁缺毋滥语义
由持仓下限承接); skip-month / 波动率调节等更多学术变体(YAGNI, 先验证四个修正是否已转正期望)。

## 架构(极简形态)

```
(不变) 信号轨 = 美股 Nasdaq 日线 ──> BacktestContext.signal_klines(引擎按 tick 截断无前视)
       成交轨 = 币安 bStock 日线(bStock sanity 回测) 或 Nasdaq 日线(R1 十年回测)
(v2)   策略 on_tick(Lua):
        周频闸(每 5 交易日才计算名单, 其余 tick 零单幂等)
        市场门: SPY(池内 SPYBUSDT 映射, 零新增通道)信号线 close > EMA200 才允许持仓
                (或持有现金; 门关闭时清仓)
        打分/确认(不变, 全部美股线): IBD RS → 牛市确认过滤
        持仓下限: 合格候选 < 3 只 → 全现金(与市场门联动, 宁缺毋滥到底)
        名单变化才调仓(truth-based diff, 不变)
```

- 打分/确认公式保持 Lua 源码可见(用户可改窗口/权重/门阈值/频率参数);
- 周频与市场门都走 ctx:klines(美股信号线), 引擎截断保证无前视, 与现有组合信号模式同构;
- R1 十年回测 = 装配层选择成交轨数据源(Nasdaq), 撮合/报告链路复用现有组合 runner。

## 门禁(本档案验收标准)

- **长期期望为正(硬门禁)**: R1 美股十年日线回测(Nasdaq 真实数据, 2016-2026 或可用全窗口)
  报告级指标: 期末收益为正 且 每 bar 期望收益 > 0 且 夏普 > 0(修正前 R2-spot 对照:
  每 bar -0.28%、夏普 -2.16)。**修正后 R2-spot/R2-futures sanity 不劣于修正前**(-24.7%/-1.65%
  参照, 不做正期望断言 — 样本太短)。
- **数据源铁律(硬门禁)**: grep 策略脚本, 打分/EMA/RS/趋势确认所用序列全部来自 ctx:klines
  (美股信号轨), 无 volume 参与指标计算; ctx:price 仅用于成交预算/撮合, 不参与指标。
- **测试纪律**: 合成数据 e2e 真撮合(周频闸/市场门/持仓下限三行为各有独立场景断言);
  R1 与 R2 真数据冒烟走 Nasdaq 官方 API + 币安公共 API 免 key 真实调用。
- **无前视**: 市场门/周频沿用 signal 截断机制, 无前视单测(改未来价断言返回不变)。

## 用户场景与测试 *(必填)*

### 用户故事 1 - 弱市空仓: 市场门 (P1)

用户运行真实数据回测, 观察到市场下行期(如 SPY 跌破 EMA200 段)策略持有现金而非追强势股挨跌,
回撤显著收窄。

**为什么 P1**: 动量崩溃是负期望主因, 市场门是修正核心。

**独立测试**: 合成数据编排 SPY 线跌破/站上 EMA200 两段, 断言门关闭段零持仓/零买单、门开启段恢复建仓。

**验收场景**:
1. **给定** SPY 信号线跌破 EMA200, **当** 策略 tick 计算名单, **则** 输出全现金(平仓 + 不建仓);
2. **给定** SPY 信号线站回 EMA200 上方, **当** 下一调仓日, **则** 恢复 top-k 建仓;
3. **给定** 市场门参数(如 EMA 窗口), **当** 修改 Lua 后重跑, **则** 行为随参数变化(源码可调)。

### 用户故事 2 - 低频调仓: 周频 (P1)

真实回测的调仓天数与换手率大幅下降(目标: 调仓交易日占比从 39% 降至 ~20% 以内, 换手从
707%/90 天降至 ~250%/90 天以内), 费用支出下降。

**为什么 P1**: 降频同时降摩擦与择时损失, 是正期望的必要条件。

**独立测试**: 合成数据 10 交易日, 仅信号变化但未到周频边界 → 零单; 到第 5/10 交易日名单变化 → 调仓。

**验收场景**:
1. **给定** 周频参数 = 5 交易日, **当** 连续 4 个交易日名单本应变化, **则** 零成交(闸未开);
2. **给定** 第 5 交易日名单变化, **当** tick 到达, **则** 正常先卖后买;
3. **给定** 名单不变, **当** 周频边界到达, **则** 零单(幂等)。

### 用户故事 3 - 分散下限: 宁缺毋滥到底 (P2)

真实回测中不再出现长期 1-2 只单票硬扛; 合格候选 <3 只时组合为空仓现金。

**为什么 P2**: 防集中度风险与弱市半仓挨跌, 是市场门的补充。

**独立测试**: 合成数据仅 1-2 只合格候选 → 全现金; 3 只以上 → 按规则建仓。

**验收场景**:
1. **给定** 池内合格候选 2 只, **当** 调仓日, **则** 不建仓(全现金);
2. **给定** 合格候选 ≥3 只, **当** 调仓日, **则** 按预算建仓 top-k。

### 用户故事 4 - R1 十年验证长期期望 (P1)

用户运行 `locus backtest --strategy bs_momentum --market nasdaq`(或等价入口), 在美股 Nasdaq
十年日线上回测, 输出含质量指标的完整报告, 判断策略长期期望是否为正。

**为什么 P1**: bStock 样本短无法证长期; R1 是"长期期望为正"的唯一验证载体。

**独立测试**: R1 真实数据冒烟(十年窗口跑通, 报告含每 bar 期望/胜率/盈亏比/夏普/回撤)。

**验收场景**:
1. **给定** Nasdaq 十年日线可用, **当** 运行 R1 回测, **则** 报告完整输出且指标可判长期期望正负;
2. **给定** 修正后策略, **当** 对照修正前 R1 基线, **则** 每 bar 期望/夏普/回撤全面改善(见门禁)。

### 用户故事 5 - 指标只用美股数据 (P0 铁律)

用户审查策略脚本与报告, 确认所有指标(动量/RS/EMA/趋势)的输入序列均为美股 Nasdaq 信号线,
币安数据不出现在任何指标计算中。

**为什么 P0**: 用户 2026-09-09 明令; bStock 量价相对美股可忽略, 币安指标无意义。

**独立测试**: grep 断言 + 代码走查(脚本中 ctx:klines 为唯一指标输入; volume 0 引用; ctx:price
仅预算)。

**验收场景**:
1. **给定** 策略脚本, **当** 检查指标输入, **则** 全部来自 ctx:klines(美股线), 无 bStock 量价参与;
2. **给定** 未来改动, **当** 有人试图用成交轨价格/量算指标, **则** 数据源铁律注释与检查挡住。

### Edge Cases

- 市场门关闭时已持仓 → 立即清仓(还是只禁止新开?定: 关闭即清仓, 与"全现金"语义一致);
- 周频边界恰逢市场门状态切换 → 门优先: 门关闭任何时候都平仓, 周频只约束建仓/换仓频次;
- 持仓 <3 只但 SPY 门开启 → 全现金(下限独立于市场门, 两者都满足才持仓);
- 信号线缺失(新上市/停更) → 该 pair 不参与打分(现状不变), 不影响市场门(SPY 单独拉取);
- SPY 信号线缺失(数据源故障) → 保守处理: 视为门关闭(空仓), 不猜测;
- R1 十年回测中池标的上市日不同 → 动态池语义(按数据首根近似上市日, 注明幸存者偏误);
- 修正前 R2 观察项(rejected 14) → 不在本档案范围(引擎拒单分类另行评估)。

## Requirements *(必填)*

### Functional Requirements

- **FR-001**: 策略必须支持市场状态门 — SPY(美股信号线)收盘价低于其 EMA200 时组合全现金,
  站上后恢复持仓; 门阈值参数(EMA 窗口等)必须在 Lua 内可调。
- **FR-002**: 策略必须支持周频调仓 — 每 N 交易日(N 默认 5, 参数可调)才重新计算名单并调仓,
  非调仓日名单变化不产单。
- **FR-003**: 策略必须支持持仓下限 — 合格候选数 < K_min(默认 3, 参数可调)时全现金。
- **FR-004**: 策略所有打分/确认/市场门指标必须仅基于美股信号线(ctx:klines); 币安数据只用于
  成交轨撮合/预算/仓位(数据源铁律, 代码注释固化)。
- **FR-005**: 系统必须提供美股成交轨回测入口(R1): 以 Nasdaq 日线为成交轨跑组合回测,
  复用现有组合 runner 与报告链路。
- **FR-006**: 组合回测报告必须输出质量指标: 每 bar 期望收益、胜率、盈亏比、平均盈/亏、
  年化、波动、最大回撤、夏普(报告字段已具备, 打印补齐)。
- **FR-007**: 组合回测必须支持成交明细导出(env 门控或正式 flag): fills / 持仓快照 / 净值曲线 /
  成交轨价格 CSV, 用于归因复算。
- **FR-008**: 策略参数(universe/top_k/market_gate/rebalance_days/min_candidates)必须在 Lua
  on_init 读取并日志披露, 默认值变更不破坏既有入口(006 兼容)。

### Key Entities

- **信号轨(美股 Nasdaq 日线)**: 指标唯一数据源; 池内每标的 ~2514 根(10 年), 引擎按执行日截断。
- **成交轨(bStock 日线 / R1: Nasdaq 日线)**: 撮合/估值载体; bStock sanity 91/220 天, R1 十年。
- **市场门信号(SPY)**: 池内 SPYBUSDT 映射, 独立于个股打分, 决定组合持仓/空仓状态。
