### 2.1 两条关键约定（D 决策）

- **`R.sg` 共享命名空间**（文件内别名 `S`）：四份文件都挂在同一个对象上，避免往 `window` 上撒私有符号。
- **状态袋 `S.st`（13 个槽位）**：原文件的 13 个可变顶层状态全部收进一个袋子 —— 拆分后**没有跨文件的自由变量**，状态归属一处可见。
- **跨文件引用一律「延迟别名」**，形如 `const onUndo = (...a) => S.onUndo(...a)`；**禁止值别名**（`const onUndo = S.onUndo` 这种）。
  理由：外壳与子文件的依赖是**双向的**（外壳装配时要用子文件的能力，子文件加载时要用外壳的工具），值别名会在对方尚未导出时**固化 `undefined`**；延迟别名把查表推迟到调用那一刻。
- **加载顺序即契约**：子文件在**加载期**就从 `R.sg` 取工具/常量 → 外壳必须先跑。顺序同时体现在两处：`assets.rs::ASSETS`（路由表由它派生）与 `index.html` 的 `<script>` 顺序。

### 5.1 抓到一个静态/接口测试**结构上抓不到**的回归

> **`ReferenceError: onUndo is not defined`**

拆分后 `strategy_editor.js` 里定义了 `onUndo`，但**忘了导出**（`S.onUndo = onUndo`），而外壳 `mount()` 直接把它挂到 `#sg-undo` 按钮上。后果：**点开策略页整片报错**。

**为什么四道静态门全绿**：

| 门 | 为何漏 |
|---|---|
| `node --check` | 语法合法 —— 这是一次**运行期**未定义引用 |
| `grep` 字面量扫描 | 只查禁用 API，不查跨文件符号完整性 |
| Rust 单测 | 只查清单/顺序/纪律，**进不了浏览器运行期** |
| Python 冒烟 | 只取静态内容断言能力存在（`renderStrategyLogs` 等），不执行页面 |

**修复**：`strategy_editor.js` 补 `S.onUndo = onUndo;`（带注释说明这条导出被外壳 `mount()` 直接依赖），外壳补对应延迟别名。

**固化为两道护栏**：

1. **`tmp/audit_042.py`** —— 静态审计：剥掉注释/字符串/正则后，逐份文件找**跨文件符号缺口**（① 引用了某符号、该符号在别处声明、本文件既无声明也无别名；② 别名 `S.N` 在本包内**没有任何** `S.N =` 导出）。修好后输出「跨文件符号审计: 无缺口」。
   - 自查出的一个假阳性根因：`declared` 集合必须**排除别名本身**（`const f = (...a) => S.f(...a)` 不是定义）—— 否则别名会被自己"证明"存在，缺口永远检不出来。
2. **真机走查作为常规环节**（见 044 converge 的同一结论）。
