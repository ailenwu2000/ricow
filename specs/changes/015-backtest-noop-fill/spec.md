# 015 功能规格: 回测撮合"零动作单"口径修复 (L4)

**状态**: 已实施 (2026-09-13) | **依据**: `specs/backtest.md` §十 遗留项 L4(2026-09-11 复核: 仍在)、2026-09-13 真实数据复现

## 一、为什么

`specs/backtest.md` §十 的 L4 是回测引擎最后一个遗留缺陷: **定向单在"目标方向无仓"时成交但零动作, 仍照收手续费并记一笔成交**。

- 触发例: hedge 模式下 `sell + position_side="long"`(= 平多) 而多仓为 0 —— 真交所该组合无仓可平, 回测却"成交"了;
- 后果: 手续费与成交笔数**虚增**, 报告比真实更差且不可解释; 对以"每笔成本/交易数"评估策略的人直接误导。

真实复现(修复前, 真实 fapi K 线 3 天, 临时探针 `probe-l4`):
`成交笔数 1 / 手续费 0.0482688000000000010047962462 / 净盈亏 -0.0482688000000000010047962462 / 拒单 0`
—— 一笔什么都没做的单, 账上凭空多出成本。

## 二、范围

**做**: 修复撮合层对"既不平也不开"请求的处置(不计费/不记笔数); 补单测; 补真实数据对照。

**不做**: 不改动正常开/平仓路径的任何记账; 不改动风控与"资金不足"的既有处置约定。

## 三、功能需求

- **FR-001 判定**: 请求在**成交那一刻**解析为"既不平仓也不开仓"(目标方向无仓且无法开仓)时, 视为零动作。
- **FR-002 市价单**: 无法挂起 → **拒单**并计入拒单数(与"资金不足""无仓可平"同一可见性), 不产生 fill、不计手续费。
- **FR-003 限价单**: 按"资金不足"同一既有约定**保持挂单**等到下个 bar —— 下一刻仓位变化后它可能变为有效的保护性平仓单; 挂单期间不计费、不记笔数。
- **FR-004 不误伤**: one-way 无仓卖出 = 合法开空, 不得被拒; 有多仓时的平多仍正常成交; 现货既有语义不变。
- **FR-005 可解释**: 拒单在报告中体现为"拒单次数", 与既有"资金不足/无仓可平"同口径。

## 四、验收标准

- **SC-001**: `cargo test --workspace` 全绿零回归。
- **SC-002**: 单测覆盖: 市价零动作单被拒(无 fee/无笔数/无 fill)、限价零动作单挂起且不计费(仓位出现后能正常成交平仓)、one-way 无仓卖出仍开空。
- **SC-003**: 真实数据对照: 修复前/后同一探针同一 K 线窗口 —— 成交笔数 1→0、手续费 0.048…→0、拒单 0→1。
- **SC-004**: 回归零差异: 不触发 L4 的策略(hedge 20d 探针、现货 shannon_grid)在修复前后**逐位一致**。
