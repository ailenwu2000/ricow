# 015 实施计划

## 一、决策

| # | 决策 | 理由 |
|:--|:--|:--|
| D1 | 判定依据 = `split_fill()` 返回 `(None, None)`, 封装为 `is_noop_fill()` | 复用既有"平/开拆分"唯一权威, 不新造第二套方向语义 |
| D2 | 市价单 → 拒单计数; 限价单 → 保持挂单 | 市价单无法挂起(必须给出终态); 限价单下一刻可能变有效, 与"资金不足保持 pending"同一既有约定, 改动面最小 |
| D3 | 判定放在**成交那一刻**(`match_pending` 与即时成交分支), 不在下单入口一刀切 | 下单时无仓 ≠ 成交时无仓; 提前拒会误伤"先挂保护性平仓单、后建仓"的正常用法 |
| D4 | 不新增护栏/配置项 | 这是撮合口径修正, 没有可调参数 |
