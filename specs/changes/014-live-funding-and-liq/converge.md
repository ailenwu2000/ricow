## 三、计划外发现

1. **`Stream` trait 被 patch 的模糊匹配吃掉**: 环境导入行 `use futures::{Stream, StreamExt};` 在插入 `use chrono::Utc;` 时被模糊匹配成 `use futures::StreamExt;`, 导致 `Stream` 未定义。教训:导入行不要用"单行片段"作为 patch 锚点, 用整块 use 组。
2. **清理未用 import 引发连锁**: 删 `spot.rs` 的 `OrderStatus` 后其测试模块 6 处引用报错 → 需在 `#[cfg(test)]` 内单独导入。删 import 前先确认测试模块是否使用。

## 四、收敛遗留

1. **真实资金费流水的入库路径未用真实数据验证** —— 需持仓跨越 UTC 00/08/16 结算点(8 小时内)才能产生流水; 现由单测覆盖解析/幂等/聚合/db 写入, 端到端留待实际运行到结算点。已在 `testnet.md` 与 tasks 中如实标注。
2. 资金费只做"记录 + 展示", 未并入 `PnlTracker` 的成交口径(A2 决定的边界)。
3. 强平只告警不动作(D7 边界)。

## 五、留档教训

1. **"账单即事实"**: 资金费有官方账单端点就不该用"费率×名义"自算 —— 后者在费率浮动/多空双向时会算错, 且无法对账。
2. **清理 import 要看测试模块**: Rust 的 `#[cfg(test)]` 使用不影响非测试构建, 但删顶层 import 会连带打断测试。
3. **告警阈值必须可关/可调, 且只提示**: 强平距离这类"接近即危险"的指标, 默认阈值太松没意义、太紧会淹没日志; 放在策略 params 里由使用场景决定, 且绝不因此自动交易。
