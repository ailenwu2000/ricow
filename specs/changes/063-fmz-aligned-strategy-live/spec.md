## 4. 差距与需求映射（用户四条需求 → 具体改动）

### 需求 1：实盘 —— 显示实际运行的策略，可新建（选策略 + 设参数）

| fmz 有 | ricow 缺 | 本轮改动 |
| -- | -- | -- |
| 独立「实盘」页 + 表格 7 列 | 只有「运行」页，列不对齐 | **新增 `实盘` 视图**（沿用 `#runs` 的数据源，改表格形态与列名对齐 fmz） |
| 「新建实盘」独立页 | 只有弹窗 | **新建实盘表单**：实盘名称 → 选策略（可搜索）→ **参数表单（带类型/默认值/说明）** → 交易对 → 模式 → 创建并启动 |
| 参数在新建时就能配 | 参数只能在详情页改 | 参数表单复用详情页那套 schema 渲染（**不新造一套**） |
| 实盘缺钱会报错 | 引擎已有 `insufficient balance` | **如实透出**，不拦（用户明说"实盘如果资金不够执行会报错"） |

### 需求 2：策略 —— 不分系统/自建，可编辑回测策略，编辑集成 AI

| fmz 有 | ricow 缺 | 本轮改动 |
| -- | -- | -- |
| 一张表混排 | 四组分区 | **改单表混排**，保留「内置/我的」**徽章**（区分来源是事实，不能丢），但不再分区 |
| `最后修改` / `创建日期` 列 | 无 | 后端补 `last_modified` / `created_at`（读盘 mtime，**读不到就不给**，不编） |
| `操作项`：编辑/复制/删除/更多 | 展开/详情/复制 | 行内文字链接：**编辑** / **复制** / **删除** / **更多** |
| 编辑页双 Tab | 全堆一页 | 拆 **`策略编辑` / `模拟回测`** 双 Tab |
| AI 助手常驻右侧 + 快捷指令 | AI 卡在详情页底部 | **AI 助手移到右侧常驻**，加 fmz 式**快捷指令按钮**（写一个均线交易策略 / 分析代码问题 / 加中文注释 …） |

### 需求 3：新建策略可用 AI 辅助编写

已有 `ai-generate`（结构化意图 → 生成 → 落盘）。**本轮只改入口位置**：从"策略页顶部一个按钮"改成 fmz 的 `新建策略 ∨` **下拉**里的第一项，与 `AI 辅助编写` 并列。

### 需求 4：编辑时 AI 辅助修改或回测；参数要有默认值和说明、可自定义；回测不管资金

| 要点 | 处置 |
| -- | -- |
| AI 辅助**修改** | 已有 `ai-edit`（两模式：调参数 / 改代码逻辑）—— 保留，位置移到右侧 AI 面板 |
| AI 辅助**回测** | **新增**：`ai-edit` 的第三种能力 —— 让 AI **看回测结果**并给出解读。已有 `ai-assess`（两份实测指标 → 影响评估），本轮把它**接进"模拟回测"Tab**，形成"跑回测 → AI 解读"闭环 |
| 参数不要复杂 | 参数表单只出 **类型 / 默认值 / 说明 / 取值框**四要素；类型是 bool 的用开关 |
| 回测不用管资金 | 回测表单**不再要求填初始资金** —— 沿用 058 的口径：真值 = 实例 TOML `[backtest].initial_cash`，**读不到就不显示该字段**（不猜默认 10 万） |
| 实盘资金不够会报错 | 引擎侧 `insufficient balance` 已有；**前端如实透出**，不做前端拦截 |

## 5. 刻意不做（避免范围失控）

| 项 | 原因 |
| -- | -- |
| 账号体系（登录/账单/工单/私信/消息中心/账号设置） | ricow 无账号，062 已定整块不做 |
| 托管者 / 托管主机 / 授权管理 / 分组管理 / 租用记录 / 调试工具 | fmz 的多人协作与平台能力，单机版无对应 |
| 交易终端 / 数据探索 / 交易所页 | 与本轮两条需求无关，另轮 |
| 策略笔记 / 描述 / 手册 / 快速操作编辑器 Tab | fmz 的多文档编辑器；ricow 的等价物是「说明」字段，已有 |
| 多策略并行实盘（一个策略起多个实例） | 后端实例模型是"策略 id = 实例 id"，一策略一实例是既有语义，改它是另一个变更 |
| 引入 React/antd/npm | 沿用 062 决策：CSP + 零依赖原生 JS |

## 6. 本轮的判据纪律（从上一轮踩的坑里来）

1. **路径靠 DOM 取，不靠猜** —— `/m/live`、`/m/strategy` 都是 404，真实路径只有侧栏 `href` 里有。
2. **别把"接口在浏览器里不返回"当服务端 bug** —— 浏览器 profile 里累积的**死 SSE 连接**会吃光连接池（062 查了半轮）。测任何东西前换全新 `--user-data-dir`。
3. **新断言必须变异验证** —— 否则是恒真的假绿。
4. **精确空白断言在 Windows 上必红** —— `core.autocrlf=true`，按空白切段匹配。
