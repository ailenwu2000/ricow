## 严重口径 bug 修复(2026-10-09, 用户两轮纠正定稿)

**用户口径(唯一定义)**: 仓位 = 币市值 ÷ 总权益 = `Q·p/(Q·p+现金)`; 每次买卖成交后按成交价精确落位 w(成交价) —— "什么价格就是什么仓位"。

**两轮错误与教训**:
1. v1 市值÷固定 C0(`T(p)=w(p)×C0/p`)→ 下跌段高价旧仓成本堆积提前耗尽现金(宽区间期末现金 0.21、价格 120 即"假打满")。
2. v2 成本÷C0 → 仍非用户口径, 被再次驳回。
3. v3(定稿)落位公式: 买 `q=(w·E−Q·p)/(p(1+w·f))`、卖 `q=(Q·p−w·E)/(p(1−w·f))`, E=Q·p+现金 按腿价估值。代数可证成交后精确 = w; w<1 时剩余现金恒 =(1−w)E>0 → **价格不到 p_low 现金绝不耗尽, 恰至 p_low(w=1)才打满**。

**回归锚点**: `test_linear_grid_position_invariant_every_fill`(渐变路径无跳空, 落位最大误差 <1e-6 精确闭合)。

**定稿后宽区间回测(SOLUSDT 1m 一年, p_low=10/100%, p_high=400/10%, start=208, 10批×1h, 1.5×ATR(1h/14), tp 10%/3×ATR, 1万 U)**:

## 间距改 1×ATR + 单边死锁修复(2026-10-09, 用户第三轮)

**用户诉求**: ①"成交后应立即撤原单重挂"确认已实现; ②成交量偏少; ③间距 1.5×ATR → 1×ATR 重跑。

**成交量偏少真因 = 单边死锁 bug**: 旧版重挂纯由成交事件驱动(on_fill / need_rehang)。跳空 bar 按开盘价成交后 ref 落到市场价之外, 穿越守卫把另一腿抑制 → 该腿永不成交 → 无事件 → 卖腿永远补不出来 → 单边行情整段零成交(1.5×ATR 实测 2026-08-23 后 9 月全月 0 成交, 期末价 118 远高于最后成交 93.8 却不动)。**这才是"感觉少了很多"的根因, 与间距无关。**

**修复(do_rehang + on_tick 各一处)**:
- on_tick 网格阶段: 现价偏离 ref 超一个间距 → 置 need_rehang(偏离触发重挂, 不再只等成交)。
- do_rehang: 重挂时若 |现价 − ref| > 间距 → ref := 现价(重锚), 两侧腿重新分列市场两侧, 顺带把仓位再平衡回 w(现价)。
- 回归锚点 `test_linear_grid_uptrend_no_deadlock`(单边上行 99→139, 断言卖成交 > 5; 旧版 = 0)。

**间距默认改 1×ATR**(lua num 兜底 + toml default)。

## 已知取舍(设计决策, 非缺陷)

- 建仓期出界同样触发 exit/wait(两阶段通用), 比"仅网格期检查"更保守。
- peak 自网格启动(建仓完成时刻)起追踪; 建仓期价格波动不计入止盈基准。
- wait 恢复时 ref 重锚现价(非最近成交价) —— 防陈旧 ref 产生穿越腿被动扫仓。
