# 051 现货线性仓位网格（linear_position_grid）规格

## 一、用户原始需求（2026-10-08，含两轮修订）

1. 投入资金 + 价格下限/对应仓位（默认 70%）+ 价格上限/对应仓位（默认 30%），仓位在区间内**线性分布**。
2. 设置开始价格；建仓改为**逐步建仓**（修订 1）：分 N 次（默认 10）、每次间隔（默认 1 小时），**低于指定价格才买入**；建仓是独立过程，建仓完成后才开始策略（上下挂单）。
3. 网格间距默认 1.5×ATR（1h K 线、14 周期），ATR 乘数与 K 线周期可调。
4. 建仓后在成交价上下 1.5×ATR 挂单（下方买单、上方卖单），量按线性仓位差额计算。
5. 每次成交立即取消原有单，记录成交价，在新成交价上下重挂两侧。
6. 超出价格区间：默认退出策略不清仓；可选不退出，等待价格回到区间。
7. 反复成交的资金落位恒按当前总权益实时计算（无沉淀资金）→ 现金收益即时参与后续仓位计算。
8. 动态止盈（修订 2，可选）：最小盈利百分比（默认 10%）+ 最高点回撤（默认 3×ATR）；网格阶段记录价格最高值，回撤超过 3×ATR 且盈利大于最小盈利 → 平仓止盈。须向用户说明：启用后可能提前下车。

## 二、验收标准

- FR-1 线性仓位：`w(p)` 线性钳制 `[pos_high_pct, pos_low_pct]`，`T(p)=w(p)×C0/p`；单测断言 w(80)=0.7 / w(120)=0.3 / w(100)=0.5。
- FR-2 逐步建仓：低于 start_price 且距上批 ≥ build_interval_hours 才市价买一批（目标总量 T(start_price) 均分）；建仓期不下任何限价单；高价到点顺延不烧步；建满进网格，ref=末笔成交价。
- FR-3 网格重挂：ref±Δ 两侧限价单（Δ=max(atr_mult×ATR, min_spacing×价格)，钳进区间、穿越守卫）；量=T 差额；任一成交 ref:=成交价全撤重挂（事件模型）。
- FR-4 出界：exit=撤单停机不清仓（halt 当 tick 显式 cancel_pending）；wait=暂停、回界内 ref 重锚现价恢复。
- FR-5 实时估值：落位恒按当前总权益（无沉淀资金）；on_stop 收益分解 + 期末 w 对照导出。
- FR-6 动态止盈：peak 自网格启动只升不降；回撤 ≥ tp_dd_atr_mult×ATR 且 (equity−C0)/C0 ≥ tp_min_profit_pct → 撤光+市价清仓+停机；tp_min_profit_pct=0 禁用；清单 description 写明提前下车风险。
- FR-7 守卫：参数越界/成本门槛 FATAL；ATR 未就绪不挂单；cap_buy/cap_sell 兜底；停摆 ≥1 天 WARN；账本交叉核对误差 <0.01。
- FR-8 注册：catalog BUILTIN + .gitignore 白名单 + 15 条内置单测 + architecture_guard 键一致。
- FR-9 回测交付：SOLUSDT 现货一年（2025-10-01~2026-10-01，1m，1 万 U）exit/wait 两组四件套，报告符合回测规范 v1（A1-A7 + B 区）。

## 三、非目标

- 不做 trailing 区间平移、geometric 间距、止损清仓（竞品对照后留 v2）。
- 不动引擎（纯策略层变更）。
