ricow

完全本地运行的多平台量化策略引擎 —— 回测 / Dry Run / 实盘。

English · 中文

纯本地 CLI。无云端依赖、无遥测、无自动更新。密钥与数据不出你的机器。

  • 单一二进制 —— ricow,由 5 个 crate 的 Rust workspace 构建。
  • 策略用 Lua 写,跑在沙箱里(无 os/io/require/loadstring/pcall;每 tick 指令预算 100 万,内存 64 MB)。
  • 只有一个配置文件:ricow.toml(权限 0600,明文,永不入 git)。
  • 四档运行:回测 → Dry Run → demo(币安测试网真实下单) → 实盘(真实资金)。

安装

# Linux / macOS
curl --proto '=https' --tlsv1.2 -LsSf https://github.com/ailenwu2000/ricow/releases/latest/download/ricow-installer.sh | sh
# Windows (PowerShell)
powershell -ExecutionPolicy Bypass -c "irm https://github.com/ailenwu2000/ricow/releases/latest/download/ricow-installer.ps1 | iex"

想用压缩包?所有平台产物(Linux x64/arm64、macOS x64/arm64、Windows x64)与 SHA256 校验和都在 Releases 页。也可以源码构建:cargo build --release。

四档运行

档位命令资金前置
回测ricow backtest --strategy shannon_grid --pair ETHUSDT --days 30无零配置
Dry Run(本地虚拟撮合)ricow start <名字>无零配置
demo(币安测试网真实下单)ricow start <名字> --demo模拟资金[exchange].demo_*
实盘(主网真实资金)live_enabled = true + ricow start <名字> --live --accept-risk真实[exchange].binance_* + 首次风险确认 + Dry Run 时长门禁

demo 与实盘都真实调用交易所接口,差别只在域名(demo-api/demo-fapi vs 主网)与凭据,两套凭据互不回落。

写你自己的策略

策略是 Lua 脚本,通过引擎提供的接口驱动(ctx、exec.*)。推荐路径在落盘前先编译门禁 + 真实 K 线沙箱回测:

ricow create --name my_strategy --pair ETHUSDT --script my_strategy.lua   # 编译门禁 + 真实 K 线沙箱回测
ricow approve                                                             # 由你在交互终端逐字确认
ricow deploy <preview_id> --token <token>                                 # 落盘到 strategies/

唯一的策略样板是 strategies/builtin/shannon_grid.lua,照它写即可。 完整 API 见 specs/lua-api.md。

安全模型

  • 密钥只在本机。只有一个 ricow.toml(权限 0600,已被 git 忽略);产品不代写密钥,也从不上传。
  • 实盘有多道门。策略必须声明 live_enabled = true;命令行须 --live --accept-risk,并有首次风险确认与 Dry Run 时长门禁。
  • 写实操作只能人来做。确认短语(部署 / 实盘)只接受在交互终端逐字输入 —— 管道、脚本、AI 工具调用喂入的一律拒绝。
  • 内置 AI 助手是只读的。能问答、跑回测、查文档;不能下单、部署或转移资金。
